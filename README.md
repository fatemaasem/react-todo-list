# Todo List

A clean and responsive task manager built with React and Vite.

## Features

- Add new tasks.
- Mark tasks as completed by clicking them.
- Restore completed tasks with another click.
- Delete individual tasks.
- Responsive layout for desktop and mobile screens.
- Keyboard-accessible task controls.

## Tech Stack

- React 19
- Vite 6
- CSS

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
git clone https://github.com/fatemaasem/todo-list.git
cd todo-list
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser.

## Production Build

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.
